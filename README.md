# OSEIS Gestion Privée

Site vitrine statique (HTML / CSS / JS) du cabinet OSEIS Gestion Privée — Wealth Management, fondé par Franck BONIN.

## Pages
`index.html`, `expertise.html`, `approche.html`, `fondateur.html`, `contact.html`, `mentions-legales.html`

## Avant mise en ligne
- Remplacer `CONTACT_EMAIL` dans `js/main.js` par l'adresse réelle du cabinet.
- Compléter les mentions légales (SIREN, ORIAS, statut, adresse…) dans `mentions-legales.html`.
- Relire la page « Le fondateur » et y ajouter parcours et photo.

## Aperçu local
```
powershell -ExecutionPolicy Bypass -File serve.ps1
```
puis http://localhost:5180
